Abstract

CodeTracer evaluates process-level tracing and localization for coding agents. This page uses the Overall F1 of the CodeTracer configuration from the main table.

Method & evaluation

  • This work focuses on a question beyond final success: whether an agent can accurately trace intermediate states and localize the source of failure.
  • It introduces CodeTraceBench and reports step-level precision, recall, and F1 for process-aware localization.
  • The main results show substantial F1 gains when the CodeTracer framework is added to different backbones.

Evaluation metrics

Overall F1 — Higher is better. Overall step-level F1 of the CodeTracer configuration. Score range: [0, 100].
