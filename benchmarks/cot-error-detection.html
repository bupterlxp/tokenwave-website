Long CoT Error Detection

🏆 GPT-4 Turbo 128K: 69.17 · Long Context · updated 2026-04-15

Paper ↗ PDF ↗

Abstract

This work evaluates whether models can detect errors in long chain-of-thought reasoning. This page uses F1 as the primary leaderboard and keeps first-error and any-error detection accuracy as auxiliary metrics.

Contributions

  • This is not a standard long-context retrieval benchmark but an evaluation of long-reasoning error detection.
  • The page puts F1 in the primary leaderboard because it better reflects overall detection quality.

Method & evaluation

  • This work introduces DeltaBench, a benchmark built from long chain-of-thought traces generated by o1-like models to evaluate whether models can detect reasoning errors inside those traces.
  • It covers math, coding, and general reasoning tasks, and annotates long CoTs at the process level so evaluation can move from final-answer correctness to step-level critique.
  • Using this benchmark, the paper studies both the effectiveness and efficiency of long CoTs and compares PRMs and critic models on fine-grained error detection.
  • The main takeaway is that long reasoning traces are not inherently reliable, and current process supervision and critic models still struggle in realistic long-CoT settings.

Evaluation metrics

F1 — Higher is better. Error detection F1. Score range: [0, 100].
