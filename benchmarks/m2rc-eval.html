Overview

Most code-completion benchmarks hand a model a single file and ask it to fill in the blank. M2RC-Eval works at the scale developers actually inhabit: the repository. A completion is judged not against an isolated function but within the surrounding project, and the benchmark repeats this test across 18 programming languages, making cross-language generalization a first-class axis rather than an afterthought.

What separates M2RC-Eval from a simple multilingual expansion is its annotation layer. The benchmark carries fine-grained labels derived from the abstract syntax tree: a bucket-level difficulty rating and a semantic completion scenario. Scores can therefore be sliced by what kind of code is being completed, not just which language it is written in. The paper pairs the benchmark with M2RC-INSTRUCT, a companion resource built to improve repository-level completion ability.

Scoring rests on average edit similarity (Avg ES), a 0–100 measure of how close the generated completion comes to the reference, averaged across languages; average exact match (Avg EM) is kept as a stricter secondary check. The leaderboard deliberately shows only direct model baselines — no retrieval pipelines, no training augmentations — so the numbers reflect what the models themselves know how to do.

Why it matters

Code assistants earn their keep inside repositories, where the correct completion depends on conventions, imports, and types defined files away. Single-file benchmarks never observe that dependence. And by scoring the same task in 18 languages, M2RC-Eval guards against a quieter failure: a model that looks strong in one familiar language and degrades across the other seventeen. The AST-based annotations add a further check, showing whether gains come from easy scenarios or hard ones.

Contributions

  • The paper distinguishes repository-level completion from ordinary single-file generation.
  • To avoid mixing retrieval or training augmentations into the leaderboard, this page shows only direct model baselines.

Method & evaluation

  • M2RC-Eval targets repository-level code completion rather than isolated function-level completion.
  • It builds a multilingual benchmark spanning 18 programming languages with fine-grained AST-based annotations.
  • These annotations cover both bucket-level difficulty and semantic completion scenarios.
  • The paper also introduces M2RC-INSTRUCT to improve repository-level completion ability.
  • Its main value is evaluating both cross-language generalization and fine-grained completion behavior.

Evaluation metrics

Avg ES — Higher is better. Average edit similarity across languages. Score range: [0, 100].
