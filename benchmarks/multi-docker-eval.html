Abstract

Multi-Docker-Eval studies automatic environment building for software engineering agents. This page uses F2P under the SWE-Builder setting.

Method & evaluation

  • This work extends software-engineering evaluation beyond code edits to the automatic construction of runnable environments.
  • Multi-Docker-Eval measures whether models can bring diverse repositories into a test-ready state across languages and setups.
  • The results show that environment building remains a major bottleneck for agentic software engineering, with large differences in success rate and cost.

Evaluation metrics

F2P — Higher is better. First-to-pass rate on the SWE-Builder framework. Score range: [0, 100].
