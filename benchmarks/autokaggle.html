AutoKaggle

Data Science Agent · updated 2026-08-03

Paper ↗ Code & Website ↗ PDF ↗

Abstract

AutoKaggle evaluates autonomous data-science work end to end: a phase-based multi-agent pipeline plans, writes, debugs, and validates complete Kaggle solutions — background understanding through feature engineering to submission. Results on this page will be populated at the next TokenWave data refresh.

Contributions

  • Treats a Kaggle competition as one deliverable pipeline, not isolated code snippets.
  • A phase-based workflow with cooperating agents (reading, planning, coding, reviewing, summarizing) plus iterative debugging and unit tests.
  • Includes a machine-learning tools library so agents assemble reliable pipelines instead of improvising every step.

Method & evaluation

  • Each competition run proceeds through fixed phases with validation gates between them.
  • Generated code is unit-tested and debugged in place before the pipeline advances.
  • Runs are scored on completion of a valid submission and on solution quality across competitions.

Evaluation metrics

Completion rate — Higher is better. Share of competition runs that end in a valid, reproducible submission. Score range: [0, 1].
