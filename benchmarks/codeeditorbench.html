CodeEditorBench

Code Editing · updated 2026-08-03

Paper ↗ Code & Website ↗ PDF ↗

Abstract

CodeEditorBench evaluates large language models on code editing rather than generation: debugging, translating, polishing, and revising code when the requirement changes. Results on this page will be populated at the next TokenWave data refresh.

Contributions

  • Frames code editing as its own capability, distinct from one-shot code generation.
  • Covers four editing scenarios — debug, translate, polish, and requirement switching — sourced from real submissions and curated exercises.
  • Provides an online judge so edited programs are executed and checked, not pattern-matched.

Method & evaluation

  • Tasks are drawn from multiple languages and difficulty tiers, each paired with test cases.
  • Models receive the original code plus an editing instruction and must return a working revision.
  • Evaluation executes the revised program against hidden tests in the judge environment.

Evaluation metrics

Pass rate — Higher is better. Share of editing tasks whose revised program passes the hidden tests. Score range: [0, 100].
