SWE-Compass

🏆 Claude Sonnet 4: 32.9 · Coding

Abstract

SWE-Compass provides a unified evaluation for agentic coding ability. This page uses the AVG under the Claude Code workflow to avoid mixing different execution environments.

Contributions

  • The paper reports results under both SWE-Agent and Claude Code workflows.
  • This page fixes one workflow so the leaderboard does not mix model differences with system differences.

Method & evaluation

  • SWE-Compass aims to unify software engineering evaluation into a framework closer to real developer workflows.
  • It spans 8 task types, 8 programming scenarios, and 10 programming languages with 2,000 curated instances.
  • Most instances are derived from authentic GitHub pull requests and refined through systematic validation.
  • The paper benchmarks strong models under both SWE-Agent and Claude Code frameworks.
  • Results reveal a clear hierarchy of difficulty across tasks, languages, and programming scenarios.

Evaluation metrics

AVG — Higher is better. Average score under the Claude Code workflow. Score range: [0, 100].
