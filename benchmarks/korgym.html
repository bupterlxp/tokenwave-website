Abstract

KORGym is a dynamic game platform for reasoning evaluation. This page uses the Avg Score from the paper's main table.

Contributions

  • KORGym replaces static questions with dynamic interactive games and emphasizes online decision-making.
  • The page uses Avg Score to stay aligned with the paper's main results.

Method & evaluation

  • KORGym extends reasoning evaluation from static benchmarks to a dynamic game platform with interactive multi-turn tasks.
  • It offers more than fifty text or vision games and supports reinforcement-learning-style scenarios, so evaluation can capture strategy, interaction, and modality effects rather than final answers alone.
  • The paper uses KORGym to study a wide range of LLMs and VLMs, showing recurring reasoning patterns within model families and a continued advantage for closed-source systems.
  • In this sense, KORGym pushes reasoning evaluation toward settings that are closer to realistic interactive environments.

Evaluation metrics

Avg Score — Higher is better. Average KORGym score. Score range: [0, 100].
