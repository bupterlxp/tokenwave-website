Abstract

FullStack Bench evaluates LLMs as full-stack coders. The displayed leaderboard uses the Overall score from the main results table.

Contributions

  • The benchmark goes beyond standalone coding tasks and targets end-to-end full-stack development.
  • This page keeps Overall as the primary leaderboard instead of splitting every domain-specific subscore.

Method & evaluation

  • FullStack Bench moves beyond isolated coding tasks and targets broader full-stack development ability.
  • It covers domains such as basic programming, data analysis, software engineering, math, and machine learning.
  • The benchmark uses real-world instructions and unit tests across 16 widely used programming languages.
  • The paper also releases SandboxFusion to execute and evaluate these multilingual tasks reliably.
  • Results show that full-stack evaluation is both more realistic and more challenging than traditional code benchmarks.

Evaluation metrics

Overall — Higher is better. Overall full-stack coding score. Score range: [0, 100].
