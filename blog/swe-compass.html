SWE-Compass: Navigating Real-World Software Engineering with Agents

2026-06-02 · SWE-Compass · 1 min read

A compass needs more than one axis. We chart coding-agent capability across task types, repository scale, and iteration depth — and show why single-number leaderboards flatten the terrain that matters most.

Ask three teams what "good at coding" means and you will get three different answers: closes issues, survives large repositories, doesn't break the build twice. SWE-Compass takes that ambiguity seriously. It spans 8 task types, 8 programming scenarios, and 10 programming languages, with 2,000 curated instances drawn from authentic GitHub pull requests and refined through systematic validation.

Fix the workflow, then compare the models

The paper evaluates every model under two agent frameworks — SWE-Agent and Claude Code. Mixing those numbers into one column would blur the line between model ability and execution environment, so our leaderboard fixes a single workflow (Claude Code) and lets models differ only in the one variable that should matter.

A leaderboard is an experiment. If two rows were produced under different harnesses, the table is comparing harnesses, not models.

Under the Claude Code workflow, the AVG column reads:

#ModelAVGSource
1Claude Sonnet 432.9Official
2Qwen3-Coder-480B-Instruct21.9Official
3Qwen3-Coder-30B-Instruct21.6Official

The spread is brutal and informative: the leader clears the runner-up by eleven points, and scores fall off quickly below the top three. Real-workflow coding remains far from saturated — the best model completes barely a third of what the benchmark asks.

Reading the terrain, not the summit

  • Task types expose different failure modes: repair-style tasks reward precision, feature-building rewards planning depth.
  • Language coverage punishes English-plus-Python overfitting; ten languages keep the evaluation honest.
  • The difficulty hierarchy across scenarios is stable between frameworks — evidence it reflects the work itself, not harness quirks.

That is what a compass is for. A single number tells you who is ahead; the axes tell you where to walk next.
