KORGym: Knowledge-Orthogonal Reasoning in Interactive Games

2026-02-16 · KORGym · 1 min read

Strip away memorized knowledge and what reasoning remains? KORGym places models in interactive game environments built on novel rules, separating genuine rule-following inference from pattern recall.

Every static benchmark eventually becomes a memory test. Questions leak into training data, solution patterns get learned as templates, and "reasoning" scores quietly turn into recall scores. KORGym's answer is to stop asking questions and start dealing hands: interactive games with novel rules, where the only way to win is to actually infer.

Games as instruments

Each environment defines rules the model has never seen, then requires multi-turn online decision-making under those rules. Because the rules are knowledge-orthogonal — deliberately disconnected from facts a model could have memorized — performance isolates the inferential machinery itself: read the rules, build a working model, act, observe, revise.

A model that reasons can play a game it has never seen. A model that recalls can only replay games it has.

Reasoning-tuned models dominate, and the ordering diverges noticeably from static reasoning suites — some models famous for benchmark math lose ground the moment rules go interactive. That divergence is the entire value of the platform: it measures the part of reasoning that static formats cannot reach.

Because games are generated dynamically, the platform also resists contamination by construction — next year's models cannot have memorized next year's boards.
