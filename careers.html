Forward-Deployed Engineer

The engineer who makes AI work inside someone else's stack.

A forward-deployed engineer is judged on one thing: whether the system runs in the customer's environment, not the vendor's demo. The work is unglamorous and unforgiving — standing up infrastructure, wiring tools and permissions together, carrying a workflow across terminal, browser, and GUI until it verifiably finishes. An agent that holds this job must sustain execution over long horizons and recover when the environment pushes back.

Environment bring-up · Incident response · Long-horizon tool & GUI workflows

Software Engineer

Ships the feature, reviews the diff, keeps the repository alive.

Software is where agent claims meet the cleanest acceptance test: the code either works or it does not. This dossier spans the full delivery loop — implementing features against a living repository, generating and completing code across languages and stacks, building interactive front ends, and the review-side craft of tracing executions and localizing faults. The gap between an agent you supervise and one you trust lives here.

Evaluation & Data Specialist

Judges model output for a living — including other agents'.

Our own profession, held to its own standard. An evaluation specialist reads long-form output and scores it consistently, finds the error buried two hundred steps into a reasoning chain, critiques formal work without rubber-stamping it, and refuses the shortcuts that quietly inflate scores. The reasoning and structured-data probes in this dossier are the same ones an eval team runs before anything ships to a customer.

Benchmark construction · Reward & critic modeling · Regression review

Watches everything, misses nothing, describes it to spec.
