The benchmarks behind the certification.

Certification standards are only as good as the evaluations behind them. Every benchmark in this dossier is designed and maintained by TokenWave — built where the field's existing measurements stop short of the work we certify.

Leader — Claude Sonnet 4.5 (Claude Code) · 40.2 · Code Agent · updated 2026-04-21

NL2Repo-Bench

Whether a coding agent can turn a natural-language brief into a complete working repository.

Leader — GPT-5 · 65.05 · Knowledge · updated 2025-12-22

CodeSimpleQA

Bilingual factual code knowledge, separated from whether a model can merely execute a snippet.

Code Editing · updated 2026-08-03

CodeEditorBench

CodeEditorBench evaluates large language models on code editing rather than generation: debugging, translating, polishing, and revising code when the requirement changes.

Open Code LLM · updated 2026-08-03

OpenCoder

OpenCoder is an open cookbook for building top-tier code language models: the complete, reproducible recipe — data pipeline, corpus, training details, and checkpoints — behind a code LLM family that matches leading models of its size.

Code Execution · updated 2026-08-03

OpenCodeInterpreter

OpenCodeInterpreter closes the loop between writing code and running it: models generate, execute, and refine code using execution results and feedback, trained on the Code-Feedback corpus of multi-turn interactions.

Leader — Kimina-Prover · 16.46 · Formal Math · updated 2026-08-03

FormalMATH

FormalMATH is a large-scale Lean4 benchmark of 5,560 formally verified statements, from Olympiad challenges to undergraduate theorems across algebra, calculus, number theory, and discrete mathematics.

Olympiad Math · updated 2026-08-03

Omni-MATH

Omni-MATH is a 4,428-problem benchmark of Olympiad-level mathematics organized into 33 sub-domains and 10 difficulty tiers, with Omni-Judge for automated answer checking.

Leader — Gemini 2.5 Pro · 89.2 · Math · updated 2026-04-21

CriticLean

Measuring whether models can serve as reliable critics for mathematical formalization in Lean.

Data Science Agent · updated 2026-08-03

AutoKaggle

AutoKaggle evaluates autonomous data-science work end to end: a phase-based multi-agent pipeline plans, writes, debugs, and validates complete Kaggle solutions — background understanding through feature engineering to submission.

Leader — Claude Opus 4.8 · 51.3 · Environment Learning · updated 2026-08-03

EdgeBench

EdgeBench measures how agents learn from real environments over ultra-long horizons: 134 real-world tasks across six domains, each supporting 12 or more hours of continuous operation.

Leader — AutoMV (M-A-P) · 24.4 · Music Video · updated 2026-08-03

AutoMV

AutoMV turns a full song into a coherent music video with a multi-agent system — and ships the first music-to-video evaluation benchmark: four categories and twelve expert criteria, with an LLM judge that tracks professional raters.

Leader — Gemini 3.1 Pro · 30.67 · GUI Agent · updated 2026-07-05

Workflow-GYM

Professional GUI work measured end to end, where one missed stage can invalidate the whole workflow.
